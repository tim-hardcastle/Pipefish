Welcome to Pipefish Author. You can use this website to create, edit, and publish Pipefish books.

We assume that you have already seen one or two Pipefish books. If so, you will realize that you're reading another one, but that it has a couple of extra dropdown menus and one more button. These allow you to edit books, including this book you're reading, which is supplied as a tutorial and playground.

In the next section of the book we will explain how to use these extra controls to edit books, and in the final section, we will look at how to make Pipefish code run in a book and interact with the various widgets you can put in your pages.
