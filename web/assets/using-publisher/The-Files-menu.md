## The VFS

This website has a virtual file system, stored in the cache of your browser, meaning that your projects will persist if you close the page, restart your computer, etc.

## The Files menu

The **Files** menu is accessible via the "Files" bar in the header.

The **Files** menu provides basic file-handling, allowing you to create files, rename them, delete them, etc. It doesn't distinguish between folders that are books and folders that aren't, or between `.md` files that are or aren't pages of books: treating folders as books is the job of the **Books** menu, which we will discuss on the next page.

The menu has the following options:

* **Open** will open a single file for editing.
* **New** will create a new file or folder.
* **Rename** will rename a file or folder.
* **Delete** will delete a file or folder.
* **Revert** will revert a file or folder.
* **Download** will download a file or folder.

This will all seem very familiar to you if you've used the Files menu inside a Pipefish book, because it is in fact the same menu. The two differences are that **Open** can only be used on files and not on folders; and that if you've set up your book to work with GitHub Pages (as described on the next page) then **Revert** will revert to the version on GitHub.
