## Pipefish books are written in markdown

We suppose that almost everyone reading this book knows what markdown is. Pipefish books implement a subset of GitHub-flavored markdown: `*italics*` gets you *italics*; `**bold**` gets you **bold**; lines beginning with `-`, `+` or `*` are list items; etc. Not all features are implemented (e.g. footnotes): they will all be supplied in later versions.

The usual subheadings are `##` and `###`: `#` is the font automatically supplied for page titles and should usually not be used for anything else.

We will look at code fences and how they can be used to contain runnable code in a later page.

## The markdown toggle.

On the right-hand-side of the main page area, near the top, you will see a button with the standard symbol for markdown. If you click on it, this will switch from viewing rendered markdown to editing the raw markdown. Clicking it again will switch back.
