Welcome to Pipefish Publisher. You can use this website to create, edit, and publish Pipefish books.

We assume that you have already seen one or two Pipefish books. If so, you will realize that you're reading another one, but that it has a couple of dropdown menus and an extra button. These allow you to edit books, including this book you're reading, which is supplied as a tutorial and playground.
